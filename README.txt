# Portfolio — Sylvain Diouf

Portfolio web responsive créé à partir du CV fourni.

## Fichiers
- `index.html` : structure du portfolio
- `style.css` : design responsive
- `script.js` : animations d'apparition au scroll

## Utilisation
Ouvrir `index.html` dans un navigateur.

## Personnalisation
Les coordonnées et le profil proviennent du CV. Les liens non présents dans le CV (GitHub, projets live, etc.) n'ont pas été inventés.
